## 6. 偏差与决策

1. **`scope.toggle`**：`切换我的排单/全店` 与 `切换日历/列表` 语义不同，
   共用 `view.toggle` 会触发页内重复 id；拆成两个能力。
2. **`formModes.actionLabels`**：迁移后发现渲染器把 mode 的 action 当文案，
   id 化后显示成 `form.submit`；补 `actionLabels` 保文案。
3. **`filter.clear` 不作为必需能力**：列表模板在空态合成该按钮，签核 brief
   不声明它；强行要求会逼出新的可见动作。
4. **Page Spec 就地迁移**：没有真实 M1 run 可重生成；`meta.version` 保持
   `0.1.0`，批次 3 用真实 run 重打包时再升。
5. **handoff 包不再有效**：v0.7 签核包内的 page spec 仍是旧值；包内 hash 与当前
   代码不再一致，视为历史证据，不修改、不重签。
