## 3. 组件映射与 id 机制（D3）

### 3.1 改了什么

- `core/renderer-html/src/index.ts`：`Switch`、`InventoryCard`、`Image`、`Icon`
  四个分支补 `data-node-id`（走 `motionAttrs`）。
- `core/figma/src/coverage.ts`：
  - `InventoryCard` 的 consumed props 从占位的 `title/value/tone` 改为实际 props
    （`name/spec/badge/badgeTone/attributes/currentLabel/currentStock/availableLabel/availableStock/inTransit`）。
  - 新增 `Switch: ["label","value","state"]`。
  - `Switch` 移出 `KNOWN_PARTIAL_TYPES`。
  - `PARTIAL_MAPPING:*` 的 coverage 状态从 `degraded` 改为 `skipped`——partial 类型
    不再「degraded 但参与 conformance 比较」，而是显式跳过并带 reason。
- `core/figma/src/compile-plan.ts`：
  - 新增 `Switch` 映射：HORIZONTAL 行 + label / 36×20 轨道 / value。
  - `InventoryCard` 从空 frame 改为带结构卡片：head（name/spec）+ 属性行 + 数字区，
    填充/圆角/padding/gap 对齐 HTML。
  - 新增 `Icon` 映射（glyph，24px）。
- 测试：
  - `core/renderer-html/tests/node-id-coverage.test.ts`：全类型 id 覆盖契约测试；
    partial 类型断言「渲染但不发 id」。
  - `core/figma/tests/coverage.test.ts`：`inventory-query` 0 degraded / 0 unmapped；
    partial 类型为 `skipped + PARTIAL_MAPPING`。
  - `core/figma/tests/plan.test.ts`：`Switch` HORIZONTAL 且有 Track；
    `InventoryCard` VERTICAL、padding 16、gap 8、有子节点。
